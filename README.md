# TMA Support Page

Support page for **TMA: Anime & Manga Tracker** — hosted via GitHub Pages.

## Live URL
[Github support page]([https://kimwin-l.github.io/tma-support](https://kimwin.github.io/tma-support/))

## What's in this repo

- `index.html` — Single-page support site with app info, FAQ, and contact details.

## Updating the page

Just edit `index.html` and push — GitHub Pages will redeploy automatically within a minute.

```bash
git add index.html
git commit -m "Update support page"
git push
```
